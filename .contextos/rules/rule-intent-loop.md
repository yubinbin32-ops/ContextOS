# 意图优先，执行靠委派

1. **OS 不是智能体**：ContextOS 提供证据、命令、变更、架构与连续性的基础设施，它不会自己跑完 explore -> change -> verify -> ship。闭环必须由某个执行者完成：主宿主、micro 或 CLI。
2. **主宿主负责判断与分配**：合同、验收、架构决策、集成与最终判断留在主对话；能委派的探索与实现不要自己先做。
3. **micro 承接有界探索**：把定位/检索/摘要/验证包成有界任务派给 micro，它自带工具循环并返回一份紧凑报告。
4. **CLI 闭合实现闭环**：多文件实现、重构、开放式修复派给 CLI，它在隔离工作区里自己完成 explore -> change -> verify -> ship，宿主用 integrate 一次性合回。
5. **照返回值走**：响应开头的 `## Next` 是按真实状态算出的下一步，默认照它调用。
6. **不手工记账、不伪造证据**：工作集来自 git 与编辑行为，回执由 verify 自动挂载，归属由 AST 派生；验证失败就再改一次，不要用 ops 改状态让它看起来通过。
7. **原生工具是逃生通道**：OS 不可用或资产非代码时可用，但要自己承担上下文与缺失的回执。
