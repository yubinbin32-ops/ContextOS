## 已确认的范围

- 不使用、不实现 Hook 路由；不把 Hook 纳入默认配置、Skill 或省 token 的验收依据。
- 移除 Cloud Hub 功能，包括云端应用、远程执行/存储路由、配置与切换、App 入口、部署引导和相关测试。现有云端配置向本地迁移时保留本地数据，不主动连接旧 Hub，不删除用户外部云资源。
- 默认开发路径保留精确读取、批量处理、修改、验证和恢复；小任务允许原生工具。
- Micro 保留现有 Key/URL/model，并支持 CLI provider。Adapter 由 AI 基于实际 CLI 生成、验证并写入项目设置；模板用于参考，接入名单不写死。
- Setup/Skill/App 引导用户选择 provider：检测 CLI、缺失时安装所选 CLI、复用登录、配置模型/思考/请求格式、验证所需任务模式。
- 子代理获得准确完整的目标、功能边界、验收标准、当前状态和必要证据。缺资料时允许作用域内 OS 或原生补取，不复制整个主对话。
- 复杂任务可在隔离工作区完成读改验循环；主代理独立验收并集成。现有只读 Micro 不静默获得写权限。
- 默认串行、指定模型，不隐式回退；不用 gpt-6-sol。开发委派优先使用已登录的 agy / gemini-3.8-flash-high。
- 去掉无收益的强制步骤、重复工具说明、成功回执复读和高频轮询。功能和限制以正确性及完整链路收益判断；保留保护数据、作用域、预算和验证真实性所需的约束。

## 委派与预算规则

每个外接任务包含目标、边界、完成标准、允许修改的文件、测试命令、base hash、限制和输出格式。完整输出保存在本地，主模型只读取有界结论和所需补丁；子代理不再委派，不实现 Hook，不部署或访问 Hub。

一次实际模型检查与任务回执确认就绪；CLI 模型列表和模型自述不单独证明真实执行。CLI 退出0不代表功能通过；必要动作被拒绝、任务偏移或验收缺失均视为未完成。

用量保留原始字段和计量语义，累计会话值不重复相加，推理/缓存不双计。父模型变少不等于总 token 或费用下降。
