# Security Policy

## Supported version

Security fixes are applied to the latest release and the `main` branch.

## Report a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Include affected versions, reproduction steps, impact, and any suggested mitigation. Do not open a public issue for an unpatched vulnerability.

Never include API keys, access tokens, private source code, or a user's `.contextos` project data in a report unless GitHub's private reporting flow is being used and the material is necessary to reproduce the issue.

## Scope

Reports about path traversal, unsafe symbol replacement, command execution, rollback failures, secret exposure, MCP input validation, and malicious graph data are particularly valuable.
